# HertPicture Distribution

Distribution website and mobile wrapper projects for HertPicture.

The web app is built with Vite, React, TypeScript, Tailwind CSS, and `lucide-react`. Android and iOS projects are generated with Capacitor and use the production web build from `dist/`.

## Requirements

- Node.js compatible with the installed Vite and Capacitor versions
- npm
- Android Studio or Android SDK for Android builds
- macOS with Xcode and Apple signing for iOS builds

## Install

```bash
npm install
```

## Web Development

Start the local Vite server:

```bash
npm run dev
```

Build the production web app:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

## Mobile Builds

Capacitor reads the production web output from `dist/` and syncs it into the native projects.

Sync both Android and iOS:

```bash
npm run mobile:sync
```

Sync Android only:

```bash
npm run android:sync
```

Build an Android debug APK:

```bash
npm run android:build
```

The debug APK is written under:

```txt
android/app/build/outputs/apk/debug/
```

Open the Android project in Android Studio:

```bash
npm run android:open
```

Sync iOS only:

```bash
npm run ios:sync
```

Open the iOS project in Xcode:

```bash
npm run ios:open
```

Important: iOS project files can be generated on Windows, but a signed iOS app build requires macOS, Xcode, and Apple signing credentials.

## Current App Identity

Capacitor config is in `capacitor.config.ts`:

```ts
appId: 'app.hertpicture'
appName: 'HertPicture'
```


## Product Metadata

Most editable product defaults live near the top of `src/App.tsx`:

```ts
const product = {
  name: 'HertPicture',
  version: 'v0.1.0',
  fileSize: '2.3 MB',
  fileName: 'HertPicture_0.1.0_x64-setup.exe',
  windowsSupport: 'Windows 10 and 11',
  installerPath: '/downloads/HertPicture_0.1.0_x64-setup.exe',
  checksum: '4b9e2791aacd9e0112b5dc50f44a8a6ffb9a914f8a912a72d42064e4894b5d5f',
  releaseDate: 'April 28, 2026',
  publisher: 'Brilord',
  supportEmail: 'support@hertpicture.app',
};
```

Before a real public launch, confirm:

- Product name
- Version number
- Installer filename
- Installer file size
- SHA-256 checksum
- Publisher or code-signing name
- Support email
- Release date
- Changelog
- Screenshot path


The browser-facing download path is:

```txt
/downloads/HertPicture_0.1.0_x64-setup.exe
```

The current preview image is:

```txt
public/screenshots/hertpicture-preview.svg
```

The browser-facing screenshot path is:

```txt
/screenshots/hertpicture-preview.svg
```

Do not use local filesystem paths in browser-facing metadata.

## Local Edit Mode

When opened on `localhost`, `127.0.0.1`, or `0.0.0.0`, the site shows a local editor toolbar.

Local edit mode can:

- Toggle inline page copy editing
- Save draft copy to `localStorage`
- Edit product and installer metadata in the browser
- Upload a Windows `.exe` to `public/downloads`
- Upload images to `public/screenshots`
- Update local theme settings

The editor and upload middleware are intended for local development only. The toolbar is hidden on normal deployed hostnames, and static production deployments do not expose the Vite dev upload middleware.

## Download Verification

The page publishes the Windows SHA-256 checksum. Users can verify the downloaded installer with PowerShell:

```powershell
Get-FileHash .\HertPicture_0.1.0_x64-setup.exe -Algorithm SHA256
```

The expected hash is:

```txt
4b9e2791aacd9e0112b5dc50f44a8a6ffb9a914f8a912a72d42064e4894b5d5f
```

## Deployment

For a static web deployment:

```bash
npm run build
```

Deploy the generated `dist/` folder to a static host such as Vercel, Netlify, GitHub Pages, Cloudflare Pages, or object storage with static website hosting.

For mobile releases, run the matching Capacitor sync command first, then build/sign from Android Studio or Xcode.
